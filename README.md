# BK7238_AT

BK7238 的 AT 固件仓库，用于发布 Sparkleiot BK7238 AT Firmware 的固件包、版本说明与相关下载资源。

本仓库主要提供：

- BK7238 AT 固件发布版本
- 固件压缩包下载
- 二进制固件下载
- 版本更新说明

## 使用说明

-  烧录完成后，可通过串口查看启动日志确认固件是否正常运行。 
-  如需进行射频信号校准，请注意当前需要拉低的 GPIO 为 `Pin11`。 
-  请优先从 Release 页面下载对应版本的固件与压缩包。
